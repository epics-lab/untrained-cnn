# untrained-cnn
Untrained CNN project

## Architecture Optimization

Optimizing untrained 3D CNN architectures for brain MRI feature extraction.
Random-weight (Untrained) CNNs used as fixed feature extractors → Random Forest for
sex classification and age regression. No CNN training involved.
